Where lyrics are kept
Spicy Lyrics
Optional. A key starting with sl_sk_ from developers.spicylyrics.org. With it, Cascade shows Spicy Lyrics' word-synced lyrics where they exist. Songs are matched to Spotify through ListenBrainz, and users can link a song by hand in Cascade when that finds nothing. Results are cached for at most 25 days and never written as files.
Who can link songs to Spotify for everyone
A link picks which Spotify track a song's Spicy Lyrics come from. Links set by the people switched on here apply to every user on this server. Everyone else can still link songs, but only for themselves: Cascade keeps those on their own computer. Administrators always can.

How songs are rated
Jellyfin has no explicit flag, so this plugin works one out for each song: a rating set by hand, then the advisory tag inside the file, then the lookups below. A match needs the same artist and title and a length within 3 seconds, otherwise the song stays unknown. Run the Find explicit songs scheduled task to check the whole library.

Animated album covers
Cascade can show a looping video cover on the now-playing view. It comes from a cover.mp4 in the album's folder (put there by hand or uploaded from Cascade), an animated cover.gif, cover.webp or cover.apng there (turned into a video once, the first time it is asked for), or from TIDAL, which has one for roughly one album in twelve.
Separated by commas. The first .mp4 name is used when saving an MP4 upload, the first .webm name for a WebM.

TIDAL
Optional. TIDAL's terms do not let one developer account be shared, so you use your own:
  1. Sign in at developer.tidal.com and create an app.
  2. Copy its client id and client secret here and save.
  3. Press Test to check them.
Lookups happen only when someone opens an album in Cascade, never as a library-wide pass. They send the album's barcode (and sometimes track ISRCs) to TIDAL. Results are kept for at most 25 days and are deleted if you clear these fields. See TIDAL's Developer Terms.
The catalog differs by country.

A look for everyone on this server
In Cascade, open the Theme panel, choose Share a look, and copy it as text (or save a .cascadepreset file), then paste or load it here. As a default it fills in the settings people never changed. Enforced, it is applied over their own settings without overwriting them. Dark or light mode and the font always stay the user's own.
