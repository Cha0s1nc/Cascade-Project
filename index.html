Cascade can translate Japanese, Korean, Chinese and Spanish lyrics into English, entirely on this computer.

Lyric translation The first time you translate a song in one of these languages, Cascade downloads that language's translation model (about 35-70 MB, from Mozilla's Firefox Translations) from Cascade's GitHub or Mozilla's servers. Nothing downloads until you press Translate. Your lyrics never leave your computer, and downloaded models can be removed in Settings.

On this Mac, Cascade uses Apple's built-in translation instead, for any of these languages installed in macOS, and nothing downloads for those. You can change this in Settings.

Install this language in macOS?

Apple Translation is recommended: it is more accurate, runs on this Mac, and downloads nothing through Cascade. This language just needs to be installed in macOS first.

In System Settings, click Translation Languages in Language & Region and download it, then press Translate again. Or use Cascade's own model for it, which downloads now.

Cascade Server Plugin Required

This feature requires the Cascade Server plugin installed on your Jellyfin server.

The plugin enables server-side karaoke lyric storage, the lyrics editor, and server-only mode. Install it through my Github page (When available, plugin unpolished) onto your server.
