Settings

The scheduled task and Recheck keep what they fetch in Jellyfin's data folder instead of writing .slrc/.lrc/.txt files beside your audio, and Cascade gets lyrics fetched live the first time a track is played. Lyrics saved from Cascade's editor still go next to the media.
Optional. A key starting with sl_sk_ from developers.spicylyrics.org. With it, Cascade shows SpicyLyrics' word-synced lyrics where they exist. Songs are matched to Spotify through ListenBrainz, and users can link a song by hand in Cascade when that finds nothing. Results are cached for at most 25 days and never written as files.

Who can link songs to Spotify for everyone

A link picks which Spotify track a song's SpicyLyrics come from. Links set by the people ticked here apply to every user on this server. Everyone else can still link songs, but only for themselves: Cascade keeps those on their own computer. Administrators always can.

Explicit songs

Jellyfin has no explicit flag, so this plugin works one out for each song: a rating set by hand, then the advisory tag inside the file, then the lookups below. A match needs the same artist and title and a length within 3 seconds, otherwise the song stays unknown. Run the Find explicit songs scheduled task to check the whole library.
Both send a song's artist and title (and ISRC when the file has one) to that service, one request per second at most. Songs the file's own tag already answers are never sent.
So other Jellyfin apps can filter on it. A metadata refresh set to replace all metadata may remove the tag until the next run of the task.

Animated album art

Cascade can show a looping video cover on the now-playing view. It comes from a cover.mp4 in the album's folder (put there by hand or uploaded from Cascade), an animated cover.gif, cover.webp or cover.apng there (turned into a video once, the first time it is asked for), or from TIDAL, which has one for roughly one album in twelve.
The first .mp4 name is used when saving an MP4 upload, the first .webm name for a WebM.

TIDAL

Optional. TIDAL's terms do not let one developer account be shared, so you use your own:
  1. Sign in at developer.tidal.com and create an app.
  2. Copy its client id and client secret here and save.
  3. Press Test to check them.
Lookups happen only when someone opens an album in Cascade, never as a library-wide pass. They send the album's barcode (and sometimes track ISRCs) to TIDAL. Results are kept for at most 25 days and are deleted if you clear these fields. See TIDAL's Developer Terms.

Server style

A theme and lyrics look for everyone on this server. In Cascade, open the Theme panel, choose Share a look, and copy it as text (or save a .cascadepreset file), then paste or load it here. As a default it fills in the settings people never changed. Enforced, it is applied over their own settings without overwriting them. Dark or light mode and the font always stay the user's own.
The two boxes only matter in Enforced mode.

Lyrics coverage

Shows which tracks in your library have word-level karaoke lyrics available from Kugou, based on the last run of the Download lyrics (Cascade Server) scheduled task. Tracks the task hasn't reached yet show as "Not checked" rather than "Missing".
